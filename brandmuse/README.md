# BrandMuse Branding Resources

This folder contains a minimal BrandMuse branding set copied for the Unique Reach hackathon prototype with user authorization on September 12, 2026.

## Assets

- `assets/brand-muse-wordmark-black.png` - black Brand Muse wordmark copied from BrandMuse-owned branding assets.
- `assets/brand-muse-wordmark-white.jpg` - white Brand Muse wordmark copied from BrandMuse-owned branding assets. The original asset used a `.png` filename but contains JPEG image data, so this copy uses a `.jpg` extension.
- `brand-tokens.css` - standalone public-facing color and font tokens derived from the BrandMuse frontend theme.
